# end-lang
The end programming language.

### Naming

Tongue in cheek: in contrast to python, end encompasses an actual end statement for namespaces.
Also, considering tools like co-pilot, it could signify the end of history for programming languages ;).

### Influences

* Syntax: [python](https://www.python.org/)
* Syntax: [Lean4](https://leanprover.github.io/)
* General: [nim](https://nim-lang.org/)
* Trait system, unsafe: [rust](https://www.rust-lang.org/)
* Memory model: [jakt](https://github.com/SerenityOS/jakt)
* Memory model: [hylo](https://www.hylo-lang.org/)
* Implementation: [tao](https://github.com/zesterer/tao)
* Effect system: [koka](https://koka-lang.github.io/koka/doc/index.html)
